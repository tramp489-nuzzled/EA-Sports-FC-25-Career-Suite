EA Sports FC 25 全方位職業模式工具包僅支援 Windows 10 與 Windows 11 作業系統。請確保您的系統為 64 位元版本，32 位元系統不受支援。目前無計劃推出 macOS 或 Linux 版本。

由於此工具會直接存取並修改遊戲存檔檔案，部分防毒軟體可能誤報為潛在威脅。這是正常現象。您可以將工具加入防毒軟體的白名單中，或在使用時暫時關閉即時掃描功能。本工具不含任何惡意程式碼，請放心使用。
